# Encapsulamento

Este repositório reúne exercícios sobre encapsulamento, um conceito crucial na orientação a objetos. O encapsulamento visa proteger dados sensíveis, garantindo que não sejam vistos e nem alterados de fora de sua classe.

Durante os exercícios, pratiquei e entendi:

- Uso de Gets, Sets e readonly.
- Uso de private para atributos, internal para classes e sua importância para o encapsulamento.
- Lógica de programação.
- Boas práticas com encapsulamento.
- Diferença entre encapsulamento e acoplamento.
- Utilização de LAMBDA e LINQ.
