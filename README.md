# Praticando C# — Conceitos de Orientação a Objetos

Este repositório reúne exercícios que desenvolvi durante meus estudos de C# na Alura. Organizei os projetos por conceitos de orientação a objetos para facilitar a consulta e mostrar o que pratiquei.

Cada pasta contém pequenos projetos focados em um conceito. Os arquivos `.csproj` e `.slnx` permitem abrir os exercícios correspondentes no Visual Studio.

Neste repositório, pratiquei:

- Encapsulamento
- Herança
- Interfaces
- Classes, propriedades e métodos
- Organização de projetos em C#

## Organização

```text
Exercicios OO
├── Encapsulamento
├── Herança
└── Interface
```

Cada projeto tem seu próprio contexto e estrutura. Este README apresenta o repositório como um todo; os detalhes específicos podem ser documentados em READMEs dentro de cada projeto.
